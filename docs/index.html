调色板图像抖动工具

基于 63 色 weplace 调色板，把图片转成像素画风格（分层投影混色 / 重心混合 / 有序抖动 / 误差扩散）

拖拽图片到这里，或点击选择
%
填宽或高 = 按比例；都填 = 强制尺寸；都不填 = 按压缩比例
按明暗分几层；层越细，少量投影色就覆盖得越准（建议 16 起）
每层聚出这么多种投影色（可不在调色板内）；越大投影越准、色差越低
每层先投影到少量颜色（大片同色），再逐个用调色板色混合出该投影色 —— 输出保证全部落在调色板内。
